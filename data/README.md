# Data provenance

`raw/Wage.rda` is the unchanged ISLR Wage data snapshot downloaded on November 4, 2026 from:

https://raw.githubusercontent.com/cran/ISLR/master/data/Wage.rda

SHA-256: `5251d6791760bceff1d8aefd7fc8eac023d00567fa078fda90595c557aa9cccc`

Documentation: https://trevorhastie.r-universe.dev/ISLR/doc/manual.html#Wage

Upstream package information and license: https://github.com/cran/ISLR/blob/master/DESCRIPTION

The snapshot contains 3,000 observations and 11 variables. Recorded years are 2003–2009. All variables have no missing values. This is a teaching version of CPS-derived data, with no survey weights or design fields. Raw wage units are not specified in the package manual.

Keep `raw/Wage.rda` unchanged. Future cleaned or derived files belong in `processed/`. The row names supplied with the data are not treated as verified person identifiers.
