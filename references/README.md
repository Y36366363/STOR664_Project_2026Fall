# Reference materials

`STOR664_Plan_original.docx` is the original project preparation document. It includes an early analysis design and code examples; use the root README and `src/wage_plan_analysis.R` for the current executable analysis.

The instructor's project handout and the scribed lecture notes are local reference materials. Both PDF filenames are excluded from Git and the public release archive. They are not required to reproduce the analysis.

Public dataset documentation: https://trevorhastie.r-universe.dev/ISLR/doc/manual.html#Wage
